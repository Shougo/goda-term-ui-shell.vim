INSTALL                                           *goda-term-ui-shell-install*

The UI "shell" of goda-term.vim (|goda-term|), which it needs:

https://github.com/Shougo/goda-term.vim

Add it to your configuration (|goda-term-configuration|):
>go
	import "github.com/Shougo/goda-term-ui-shell.vim/ext/ui/shell"

	b.AddUI(shell.New())
<

UI SHELL                                                   *goda-term-ui-shell*

A buffer with a prompt: each command line runs in a pseudo terminal of its
own (ConPTY on MS-Windows 10 1809 and later; pipes on an older one: no
colors, and no terminal for a command that asks for one), and its output,
with its ANSI colors, is written in the buffer.
Its 'filetype' is "goda-term-shell".

The command line is not given to a shell: it is words with quotes and
backslashes, leading NAME=value assignments, $VAR and ${VAR}, ~ and globs,
redirections and pipes.  A directory alone ("../", "./sub", "/tmp") is "cd"
to it.

The redirections of a command, done left to right as in a shell:
	< {file}	The input from {file}.
	> {file}	The output to {file} (made empty first).
	>> {file}	The output added to {file}.
	2> {file}	The error to {file} (2>> to add to it).
	2>&1		The error where the output goes (>&2: the output
			where the error goes).
A descriptor (0, 1 or 2) may be before "<", ">" or ">>"; the file is a
word (quotes, $VAR, ~; a glob must give one file), and the space before it
may be left out ("2>err").  "make > log 2>&1" writes both into log; "make
2>&1 > log" only the output, the error goes to the buffer.  A builtin has
none.  Not yet on MS-Windows (an error).

Commands in a pipe ("a | b | c") run together, the output of each the
input of the next; the error of each goes to the buffer.  Each has its own
assignments and redirections (one takes the place of the pipe: "a > log |
b" gives b nothing).  Its exit code is that of the last.  "|" at the end
of a line goes on in the next one.  An alias may be a pipe: the words after
it go to its last command.  A builtin cannot be in a pipe.  <C-c>
("terminate") interrupts all of them.
Only the first command reading or writing the terminal has it as its
controlling terminal: a later one cannot open /dev/tty, as a sudo or an ssh
asking a password ("echo text | sudo tee file").  Not yet on MS-Windows
(an error).

Its commands run one after another, as in a shell: "a && b" runs b after a
succeeded, "a || b" after it failed, "a; b" anyway ("cd" among them changes
the directory of the next ones).  A command interrupted ("terminate") ends
them.  The command line is one line of the history.  "&&" or "||" at the
end of a line goes on in the next one.

A command line goes on in the lines under its prompt, as in a shell: a
quote not closed, or a backslash at the end, makes "executeLine" go to a
new line instead.  A command line pasted with its lines is executed as one.
A new line out of quotes would start a second command: it is an error.

The builtins:

cd [{dir}]	Change the directory ($HOME without one, "-" the previous one):
		that of Vim too (|chdir()|, |DirChanged|).
history		Print the history.
time {command}	Run {command}, and print how long it took.
vim {file}	Edit {file}.
with [{word}...]
		Start the next command lines with {word}s (none: no more).

The output is that of a line printer: a line overwritten by "\r" and some
escape sequences (a progress bar) is overwritten; the other escape sequences
are dropped.  Full-screen programs are for |goda-term-ui-terminal|.

PARAMS                                              *goda-term-ui-shell-params*

aliases			(dict)
		Replace the first word of a command line: {"ls": "ls --color"}.

ansiColorHighlights	(dict)
		The highlights of the output: "fgs" and "bgs" (16 highlight
		groups of the ANSI colors), "bold", "italic", "underline".

commandLineHighlights	(dict)
		The highlights of the command line being typed, as
		fast-syntax-highlighting makes them in zsh, by kind:
		"command" (an executable of $PATH, or a path to one),
		"builtin", "alias", "precommand" ("sudo", "env", ... before
		the command), "directory" (a path to one: "cd" to it),
		"separator" ("&&", "||", ";" between the commands, and "|"),
		"redirect" (">", "2>&1", ...: the file after it is not a
		command),
		"unknown" (none of these), "option", "assignment" (NAME= of
		NAME=value), "singleQuote", "doubleQuote", "variable",
		"escape", "glob", "path" (one that exists).  A kind of ""
		is not highlighted.
		Default: >vim
		#{alias: 'Function', assignment: 'Identifier',
		\ builtin: 'Statement', command: 'Function',
		\ directory: 'Directory', doubleQuote: 'String',
		\ escape: 'SpecialChar', glob: 'Special', option: 'Type',
		\ path: 'Underlined', precommand: 'Statement',
		\ redirect: 'Operator', separator: 'Operator',
		\ singleQuote: 'String',
		\ unknown: 'Error', variable: 'Identifier'}
<
cwd			(string)
		The directory.
		Default: the current directory

exprParams		(string[])
		The params whose strings are Vim expressions (of uiParams, the
		params as given).
		Default: ["winCol", "winRow", "winHeight", "winWidth"]

floatingBorder		(string | list)
		The border of a floating window (Neovim).

flushIntervalMs		(number)
		How often the output is written.
		Default: 100

noSaveHistoryCommands	(string[])
		Commands not written in the history.

passwordPattern		(string)
		When the output matches it (a Go regexp), a password is asked
		(|inputsecret()|).

prompt			(string)
		Default: "%"

promptHighlight		(string)
		Default: "Identifier"

promptPattern		(string)
		The prompt, a Vim regexp.
		Default: "% "

shellHistoryMax		(number)
		Default: 500

shellHistoryPath	(string)
		The history file.  A command line of several lines has a
		backslash at the end of each line but the last (as zsh writes
		it).

split			(string)
		"" (the current window), "horizontal", "vertical", "farleft",
		"farright" or "floating" (Neovim).

startInsert		(boolean)
		Start in Insert mode.

userPrompt		(string)
		A Vim expression shown above the prompt (lines by "\n").

userPromptHighlight	(string)
		Default: "Special"

userPromptPattern	(string)
		The lines of the user prompt, a Vim regexp.
		Default: "| .*"

winCol, winHeight, winRow, winWidth	(number | string)
		The size and the place of the window: numbers or expressions
		(|exprParams|).

ACTIONS                                            *goda-term-ui-shell-actions*

cd		{directory}: the shell goes there.
executeLine	Execute the command line of the cursor (that of another
		prompt: in a new prompt).  Typed in the command running, if
		any.  With a quote not closed, or a backslash, "&&" or "||" at
		the end: a new line of it.
insert		{str}: typed in the command running, or in a new prompt.
nextPrompt	The cursor goes to the next prompt.
pastePrompt	The command line of the cursor, in a new prompt.
previousPrompt	The cursor goes to the previous prompt.
pushBufferStack	The command line is put aside: it comes back in the prompt
		after the next command.
redraw		Redraw the prompt.
send		{str}: executed.  With {noSaveHistory} (v:true), it is not
		written in the history: >vim
		call goda_term#ui#do_action('send',
		      \ #{str: 'cat ' .. file, noSaveHistory: v:true})
<
setCommandLine	{str}: the command line of a new prompt.
terminate	End the command running.
