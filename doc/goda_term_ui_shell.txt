INSTALL                                           *goda-term-ui-shell-install*

The UI "shell" of goda-term.vim (|goda-term|), which it needs:

https://github.com/Shougo/goda-term.vim

Add it to your configuration (|goda-term-configuration|):
>go
	import "github.com/Shougo/goda-term-ui-shell.vim/ext/ui/shell"

	b.AddUI(shell.New())
<

==============================================================================
UI SHELL                                                   *goda-term-ui-shell*

A buffer with a prompt: each command line runs in a pseudo terminal of its
own (ConPTY on MS-Windows 10 1809 and later; pipes on an older one: no
colors, and no terminal for a command that asks for one), and its output,
with its ANSI colors, is written in the buffer.
Its 'filetype' is "goda-term-shell".

The command line is not given to a shell: it is words with quotes and
backslashes, leading NAME=value assignments, $VAR and ${VAR}, ~ and globs;
no pipes, no redirections.  A directory alone ("../", "./sub", "/tmp") is
"cd" to it.  The builtins:

cd [{dir}]	Change the directory ($HOME without one, "-" the previous one):
		that of Vim too (|chdir()|, |DirChanged|).
history		Print the history.
time {command}	Run {command}, and print how long it took.
vim {file}	Edit {file}.
with [{word}...]
		Start the next command lines with {word}s (none: no more).

The output is that of a line printer: a line overwritten by "\r" and some
escape sequences (a progress bar) is overwritten; the other escape sequences
are dropped.  Full-screen programs are for |goda-term-ui-terminal|.

PARAMS                                              *goda-term-ui-shell-params*

aliases			(dict)
		Replace the first word of a command line: {"ls": "ls --color"}.

ansiColorHighlights	(dict)
		The highlights of the output: "fgs" and "bgs" (16 highlight
		groups of the ANSI colors), "bold", "italic", "underline".

cwd			(string)
		The directory.
		Default: the current directory

exprParams		(string[])
		The params whose strings are Vim expressions (of uiParams, the
		params as given).
		Default: ["winCol", "winRow", "winHeight", "winWidth"]

floatingBorder		(string | list)
		The border of a floating window (Neovim).

flushIntervalMs		(number)
		How often the output is written.
		Default: 100

noSaveHistoryCommands	(string[])
		Commands not written in the history.

passwordPattern		(string)
		When the output matches it (a Go regexp), a password is asked
		(|inputsecret()|).

prompt			(string)
		Default: "%"

promptHighlight		(string)
		Default: "Identifier"

promptPattern		(string)
		The prompt, a Vim regexp.
		Default: "% "

shellHistoryMax		(number)
		Default: 500

shellHistoryPath	(string)
		The history file.

split			(string)
		"" (the current window), "horizontal", "vertical", "farleft",
		"farright" or "floating" (Neovim).

startInsert		(boolean)
		Start in Insert mode.

userPrompt		(string)
		A Vim expression shown above the prompt (lines by "\n").

userPromptHighlight	(string)
		Default: "Special"

userPromptPattern	(string)
		The lines of the user prompt, a Vim regexp.
		Default: "| .*"

winCol, winHeight, winRow, winWidth	(number | string)
		The size and the place of the window: numbers or expressions
		(|exprParams|).

ACTIONS                                            *goda-term-ui-shell-actions*

cd		{directory}: the shell goes there.
executeLine	Execute the command line of the cursor (that of another
		prompt: in a new prompt).  Typed in the command running, if
		any.
insert		{str}: typed in the command running, or in a new prompt.
nextPrompt	The cursor goes to the next prompt.
pastePrompt	The command line of the cursor, in a new prompt.
previousPrompt	The cursor goes to the previous prompt.
pushBufferStack	The command line is put aside: it comes back in the prompt
		after the next command.
redraw		Redraw the prompt.
send		{str}: executed.  With {noSaveHistory} (v:true), it is not
		written in the history: >vim
		call goda_term#ui#do_action('send',
		      \ #{str: 'cat ' .. file, noSaveHistory: v:true})
<
setCommandLine	{str}: the command line of a new prompt.
terminate	End the command running.
